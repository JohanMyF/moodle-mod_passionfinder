# PassionFinder

PassionFinder is a Moodle activity module for reflective best-worst choice activities.

Teachers define categories, prompts, and item lists. Learners are shown small sets of items and choose exactly one item they feel most drawn to and one item they feel least drawn to. Later development phases will generate balanced choice sets, record learner responses, calculate relative preference scores, and produce reflective reports.

This first build is an installable skeleton with database tables, activity settings, basic JSON validation, and a safe placeholder view page.
